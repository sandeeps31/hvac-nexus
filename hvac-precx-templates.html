Templates

Select or create a template
Templates are reusable area-level pre-commissioning checklists. Each template has sections grouped by trade.
—
Import from Excel
Upload a .xlsx file to create a new template from its content.
Your file should have a sheet named Template (or it will use the first sheet) with these columns:
TYPE NAME
SECTIONGeneral / Documentation
ITEMApproved HVAC shop drawings available
ITEMEquipment submittals approved
SECTIONMechanical Completion – Air Side
ITEMAHUs installed and aligned
Rules:
  • SECTION rows start a new section. Items below them belong to that section.
  • ITEM rows add a check-line to the current section.
  • Rows with empty NAME are ignored. Rows above the header are also ignored.
  • Sign-off trades are configured per-section when filling out an area checklist (not in the template).
